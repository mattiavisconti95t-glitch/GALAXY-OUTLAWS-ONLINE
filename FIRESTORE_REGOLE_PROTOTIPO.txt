REGOLE FIRESTORE - PROTOTIPO PRIVATO, NON PER PRODUZIONE
Sostituisci le regole attuali in Firestore > Regole con queste e premi Pubblica.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /rooms/{roomId} {
      allow create: if request.auth != null
        && request.resource.data.host == request.auth.uid
        && request.resource.data.order.size() == 1
        && request.resource.data.order[0] == request.auth.uid
        && request.resource.data.phase == 'lobby';
      allow get: if request.auth != null;
      allow list, delete: if false;
      allow update: if request.auth != null && (
        request.auth.uid in resource.data.order
        || (
          resource.data.phase == 'lobby'
          && request.resource.data.phase == 'lobby'
          && request.resource.data.order.size() == resource.data.order.size() + 1
          && request.resource.data.order.hasAll(resource.data.order)
          && request.auth.uid in request.resource.data.order
          && request.resource.data.order.size() <= resource.data.limit
          && request.resource.data.diff(resource.data).affectedKeys().hasOnly(['order', 'players'])
        )
      );
    }
  }
}

ATTENZIONE: prototipo NON sicuro contro manipolazione. Un membro può modificare lo stato completo della stanza e le mani degli altri giocatori sono leggibili da chi conosce il codice. Non usare con giocatori non fidati. Per una versione pubblica servono mani private, regole per campo e logica autorevole server-side.
